# Ethical Design — folder convention

Course: **Ethical Design**, HU MDDD Block B (Problem Space). See `COURSEWORK.md` for what's due; see the root
`HU-MDDD/CLAUDE.md` for programme-wide rules (AI-use logging, don't silently make scope decisions).

*Set up 2026-11-09, mirroring the Block A courses in `Fundamentals-Block-A/`.*

## Layout

- **`W1/`, `W2/`, …** — one folder per teaching week: lecture PDFs, that week's readings, my
  notes/summaries, and small per-week deliverables. Only `W1/` exists so far; add `Wn/` as each week starts.
- **`readings/`** — shared readings not tied to one week (single copy at course root).
- **`discussion-log/`** — one condensed chat log per working day (`YYYY-MM-DD.md`); format in its `README.md`.
- **Course root** — `COURSEWORK.md` (tracker), `exam-sim.md` + `corrections.md` (exam-sim system, see root
  `CLAUDE.md`).
- Any assessed project gets its own folder at course root with its own `CLAUDE.md` + `docs/`
  (provenance, decision log, AI-build log).

New week's material goes in its own `Wn/` folder; update `COURSEWORK.md` links when moving things.
